## Working with Data Types

- Number: Numbers in JavaScript can be whole numbers or decimals and are used for mathematical operations without quotation marks.

- String: A string is a sequence of characters enclosed in quotation marks, used to represent text in JavaScript.

- Variable: A variable is a named storage location in memory that can hold different types of data, allowing for dynamic programming.

- console.log(): The console.log() function is used to display output in the console, helping developers debug and view variable values.

- Boolean: A boolean represents a true or false value and is used for conditional statements in JavaScript.
